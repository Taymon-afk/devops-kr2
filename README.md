## Что сделано

Приложение Flask запускается через Gunicorn в контейнере Docker.
Redis хранит счётчик посещений в отдельном контейнере.
Контейнеры запускаются через Docker Compose.

Порт приложения 8001 доступен только внутри виртуальной машины.
Redis не опубликован на хосте и защищён паролем.
Данные Redis сохраняются в именованном томе redis_data.

Nginx принимает запросы для api.devops.local по HTTPS и
передаёт их приложению. Для HTTPS используется самоподписанный
сертификат. HTTP перенаправляется на HTTPS.

## Запуск на сервере

Создать файл .env по образцу .env.example, задать свой
REDIS_PASSWORD и ограничить доступ к файлу:

    chmod 600 .env
    docker compose up -d --build

Проверить состояние:

    docker compose ps
    curl http://127.0.0.1:8001/health
